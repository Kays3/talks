# Talks

Slides, written reports and abstracts from talks by Kaisar Dauyey and Shinji Nakaoka
(Laboratory of Mathematical Biology, Faculty of Advanced Life Science, Hokkaido University).
The links open each file in the browser, so you do not need git to read them.

| Date | Talk | Slides | Report | Abstract |
|---|---|---|---|---|
| 2026-09 | [A Foundation-Model T-cell Dysfunction Screen: Translational Candidates, Then a Full Audit](2026-09-lung-tcell-imrad/) | [PDF](2026-09-lung-tcell-imrad/slides.pdf) · [PowerPoint](2026-09-lung-tcell-imrad/slides.pptx) | [PDF](2026-09-lung-tcell-imrad/report.pdf) · [Word](2026-09-lung-tcell-imrad/report.docx) | [text](2026-09-lung-tcell-imrad/abstract.md) |

Each talk has its own folder. The files for readers are at the top of that folder. Its `source/`
subfolder holds the generators and checksums; unpublished input data is left out, and each
`source/README.md` says what is missing.
