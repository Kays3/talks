# Fonts

No font files are needed or shipped. The deck uses only the PDF standard-14 fonts, which
ReportLab references by name and does not embed (`pdffonts` on the built PDF: Helvetica,
Helvetica-Bold, Helvetica-Oblique, Courier, Courier-Bold, Symbol, all Type 1, emb = no).
Every PDF viewer supplies these, so nothing needs to be installed.
